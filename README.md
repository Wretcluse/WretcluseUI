# WretcluseUI

**Minimal UI enhancements without unnecessary options.**

WretcluseUI is a personal collection of lightweight World of Warcraft interface improvements, customizations, and utilities.

Built around a simple philosophy: improve the default Blizzard interface while preserving its familiar appearance and functionality.

## Features

- Unit frame and nameplate enhancements
- Cast bar and cooldown display adjustments
- Small quality-of-life improvements
- Additional interface utilities
- Modular Lua files for easier maintenance

## Installation

1. Download the latest ZIP from the repository's Releases section, when available.
2. Extract the `WretcluseUI` folder into your World of Warcraft `_retail_/Interface/AddOns/` directory.
3. Enable WretcluseUI from the in-game AddOns menu.

## Compatibility

Developed for World of Warcraft Retail (Midnight). Individual features may require adjustments following Blizzard updates.

## Philosophy

No complicated configuration menus. No unnecessary features. Just small improvements to the World of Warcraft experience.
